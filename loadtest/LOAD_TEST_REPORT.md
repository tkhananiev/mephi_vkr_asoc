## 1. Нефункциональные требования (зафиксировать по результатам)

| ID | Требование | Целевое значение | Как проверяли | Результат (да/нет) |
|----|------------|------------------|----------------|---------------------|
| NFR-SCALE-1 | Автомасштабирование HTTP-слоя ASOC по CPU | HPA при **средней утилизации CPU ≥ 90%** от `requests` увеличивает число подов | Grafana + `kubectl get hpa -n asoc` во время wrk | |
| NFR-SCALE-2 | Верхняя граница устойчивой работы | RPS/соединения до появления деградации (см. критерий ниже) | Наращивание `-c` / длительность `d` в wrk | ASOC: _уточнить RPS/коннекты_ |
| NFR-AVAIL-1 | Доступность при целевой нагрузке | Доля HTTP **5xx** \< 1%, успешные ответы wrk | Счётчики wrk / логи ingress | |

**Критерий деградации (единый для обоих продуктов):**  
любой из: рост **p99 latency** на 2× от базового уровня, \>1% **5xx**, массовые **таймауты** wrk, рестарты подов **OOMKilled** / **CrashLoop**.

**Порог CPU для HPA (зафиксировано в коде/манифесте):** `averageUtilization: 90` — `deploy/k8s/hpa.yaml`.

## 2. Тест-кейсы

### 2.1 ASOC

| ID | Сценарий | Эндпоинт | wrk-параметры (-t/-c/-d) | Ожидание |
|----|----------|----------|-------------------------|----------|
| TC-A1 | Базовая линия | `GET /health` (api-service) | малые -c | Стабильные 200, низкая латентность |
| TC-A2 | Рост нагрузки | то же | ступенчато ↑ -c | Рост CPU, при ~90% — рост реплик HPA |
| TC-A3 | Нагрузка на БД | `GET /api/v1/groups` (processing) | средние/высокие -c | Масштабирование processing-service, рост latency при пределе |
| TC-A4 | Длительный прогон | выбранный эндпоинт | -d ≥ 10–15 min | Отсутствие утечек/деградации к концу окна |

_Дополнительно: приложить скриншоты Grafana (CPU по подам, виджеты **HPA текущие реплики**), вывод wrk._

### 2.2 Defect Dojo

| ID | Сценарий | URL | wrk-параметры | Примечание |
|----|----------|-----|----------------|------------|
| TC-D1 | Базовая линия | например `/login` или REST | согласовать с ASOC | Без одновременного ASOC |
| TC-D2 | Рост нагрузки | то же | **те же** -t/-c/-d, что TC-A2 | Сравнимость |
| TC-D3 | Длительный прогон | то же | -d как TC-A4 | |
